$$S = [E, C, R] \in [0, 1]^3$$

$$\text{Rendimiento} = \frac{C \cdot R}{E + \epsilon} \quad (\epsilon = 0.05)$$

- **Colapso Entrópico ($E \to 1, C \to 0$):** Bucle reactivo cerrado con drenaje masivo de ancho de banda cognitivo.
